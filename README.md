This is a simple proof of concept for module loading using a method called "DLL-Proxy"
Basically u build this example as *32bit project* and u change the output DLL's name to "Version.dll"
U drop it in the targeted desired program -- A lot of old games that are still 32-bit are using Version.dll even if its not present in their directories.
~
This was mainly used for MU Online but I bet it would work on many other games aswell.
